## 简介

这期主要更新燕子启动器里的「燕幕」：按住 Win 呼出一层桌面信息层，松开退出；点击组件可以输入，点击空白处退出；拖拽空白格子进入编辑模式，自由摆放组件。

本次重点：
- 燕幕组件真正落地：便签、待办、书签、所有应用图标、桌面文件夹等。
- 组件内部数据接入云同步，便签内容可以在公司电脑、家里电脑、笔记本之间同步。
- 同步改成燕幕专用小文件，不再每次同步完整扩展包，右上角可查看状态并手动同步。
- 交互细节优化：按住 Win 输入时不再触发系统快捷键，空白单击退出，拖拽才进入编辑。
- 组件布局更响应式，调整窗口高度后内容会跟随填充。

## 视频文案

### 0:00 开场

这期继续更新燕子启动器。之前它更像一个快速启动器，这次我把「燕幕」补完整了：它是一层可以随时呼出的桌面信息层。

按住 Win，燕幕出现；松开 Win，燕幕消失。它不是普通窗口，而是临时覆盖在桌面上的一层信息面板。

### 0:15 查看与输入

比如这里放了便签、待办、书签和桌面文件夹。  
按住 Win 只是查看；如果我点击便签，就可以直接输入。

输入结束后，不需要找关闭按钮，点一下组件外的空白格子，燕幕就退出。  
如果是在空白区域拖拽，才会进入编辑模式，用来框选创建新组件。

### 0:40 编辑模式

左上角现在有一个画笔图标。点击它，或者拖拽空白格子，就会进入编辑模式。  
进入编辑模式后画笔会变蓝，状态更明确。

在编辑模式里，可以拖动组件、调整大小、删除组件，也可以新增组件。  
这次还修了很多响应式问题，组件高度变了以后，里面的内容会跟着填充，不会只显示一半。

### 1:10 组件更新

这次把之前一些占位组件真正落地了。  
网页监控改成了书签组件，可以直接添加常用网站。  
还加了所有应用图标组件，可以快速打开应用。  
桌面文件夹组件可以直接显示桌面文件，适合临时文件很多的人。

便签和待办也不再只是本地玩具，组件内部数据现在接入了云同步。

### 1:40 云同步

同步走的是 WebDAV，所以可以用坚果云。  
比如白天在公司电脑上改了便签，晚上回家打开燕幕，会先检查云端状态，然后把最新内容拉下来。

为了避免浪费流量，燕幕没有每次下载完整扩展包。  
它只同步一个燕幕专用的小 JSON 文件，平时先检查远端修改时间，只有真的变化时才上传或下载。

右上角有同步状态，显示同步中、已同步、已上传、已拉取或者同步失败。  
如果你想马上同步，也可以直接点右上角的同步状态。

### 2:15 交互修复

还有一个细节是 Win 键。  
之前按住 Win 输入时，系统可能会触发 Win 加字母的快捷键，比如听写或者其它系统操作。  
现在燕幕触发后会处理这个状态，输入组件内容时不会再乱触发系统快捷键。

同时，点击空白退出、拖拽进入编辑、点击组件输入，这几个动作现在区分得更清楚。

### 2:45 结尾

这次更新以后，燕幕更像一个真正可用的桌面信息层：  
轻按查看，点击输入，拖拽编辑，跨设备同步。

如果你也想要一个开源、可自定义、可以替代一部分 Quicker 工作流的 Windows 启动器，可以到 GitHub 看看燕子启动器。
